CodeAlpha Internship
Task 1 – Basic Network Sniffer

Description:
This project is a Python-based network sniffer developed using
the Scapy library.

Features:
- Captures network packets
- Displays source IP address
- Displays destination IP address
- Identifies TCP, UDP and ICMP protocols
- Displays available payload information
- Displays packet length

Technologies Used:
- Python
- Scapy
- Python IDLE
- Npcap

How to Run:
1. Open network_sniffer.py in Python IDLE.
2. Press F5.
3. Generate network activity using a browser.
4. The program captures 20 packets and displays their details.

Purpose:
This project demonstrates the basic structure of network packets
and helps understand how data flows through a network.
